# Sreehari S. — Developer Portfolio

A responsive, static portfolio created from the supplied LinkedIn profile PDF.

## View locally

Open `index.html` in a browser. No installation or build step is needed.

## Customize

Edit the text in `index.html` and the design in `styles.css`. The email and LinkedIn links use the contact details in the supplied profile. The work section describes documented areas of experience, since the profile did not include named projects, screenshots, or measurable outcomes.

This folder is a local copy. It has not been deployed.
